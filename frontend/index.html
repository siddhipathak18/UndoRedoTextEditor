DSA Concept: Two-Stack Undo/Redo Editor

  • Modification (Insert / Delete / Apply): Pushes active text snapshot to Undo Stack, updates buffer, and clears Redo Stack.
  • Undo: Moves active text snapshot to Redo Stack and pops previous state from Undo Stack.
  • Redo: Moves active text snapshot to Undo Stack and pops state from Redo Stack.
